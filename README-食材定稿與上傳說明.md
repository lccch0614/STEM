# 食材資料及香港常用份量定稿

更新日期：2026-10-27  
資料版本：2026-10-27-final-v1

## 定稿結果

原有127項食材已重新檢視。正式學生清單保留116款，每款都有熱量、總碳水化合物、蛋白質、脂肪及總膳食纖維五項數據，共580個數值，並逐項對照官方原始記錄。沒有把未列值、微量或不同定義的數字填成零。

USDA的560個數值以重新下載的官方SR Legacy及Foundation CSV資料集核對，檔案校驗值與原始資料一致。日本文部科學省的20個數值，則重新下載四份原始食物記錄核對。

每款食材最少有一個有來源的常用單位，共179個選項；原本自行輸入準確克數的功能保留。新增的香港兩是司馬兩，1兩＝37.7994克，畫面約為37.8克。這是實際重量換算，不是營養「食物交換份」的40克近似值。

食物成分數據是指定食物樣本、配方或品種的參考值；碗、杯、個、片等重量受大小、水分及裝填影響，故顯示「約」，並保留生熟及可食部分狀態，不能保證每件實物剛好同重。若要準確記錄該次材料重量，仍可自行輸入秤重克數。

## 碗份量

- 白飯：1碗約198克；半碗約99克。
- 熟意粉／通心粉：1碗約175克；半碗約87.5克。
- 熟麥皮：1碗約293克。
- 熟藜麥：1碗約232克。
- 熟糙米飯：引用另一本衞生署資料的240毫升參考碗，1碗約250克；單位已明確註明240毫升。
- 乾原片燕麥：同一240毫升參考碗，原表⅓碗約27克，換算1碗約81克。

白飯、意粉、麥皮及藜麥直接引用本次核對的衞生署《熱量知多少》份量，不是把原有USDA量杯改名為碗。其他食物採用有來源的個、隻、片、粒、茶匙、湯匙、杯或香港兩；沒有為沒有直接證據的「一把」「一包」「一碗」猜重量。液體也沒有一律把毫升當作克。

## 已補核的五項

以下食材改為使用另一筆資料齊全的USDA官方記錄，五項數據全部來自同一筆記錄，並非只借另一款食物的纖維填零：

- 去皮雞胸肉：SR記錄171077。
- 養殖大西洋三文魚：SR記錄175167。
- 生蝦仁：SR記錄174210；名稱改為「蝦仁（生，混合品種）」，保留來源可能含保水添加物的說明。
- 大西洋鱈魚：SR記錄171955；來源沒有指定野生／養殖，故移除原名稱的「野生」。
- 羅非魚：SR記錄175176；來源沒有指定野生／養殖，故移除原名稱的「養殖」。

這些官方記錄有明列總膳食纖維為0；沒有因為食物是肉或魚就自行推定為零。原記錄、改用記錄及改動前後數值均保存在審核JSON。

## 已抽起的11項

以下是現有記錄未能符合本版五項數據齊全的要求，不代表這些食物本身沒有營養或所有資料庫都沒有資料。它們已移出`foods.json`及學生選單，另外保存在審核記錄：

- 蒸饅頭：原來源的纖維定義不是本版使用的總膳食纖維。
- 高鈣芝士片：沒有指定品牌及完整產品標籤。
- 菜心：原記錄提供可獲得碳水，不能直接當作總碳水。
- 節瓜：碳水定義不符，脂肪只列微量，不能自行填零。
- 蒸魚豉油：沒有指定產品的完整營養標籤。
- 鯇魚腩：尚未核實完全對應魚腩部位及狀態的完整記錄。
- 叉燒（一般成品）：原記錄的碳水定義不符總碳水。
- 蒸水豆腐：未能以完整來源對應指定蒸後狀態。
- 枝竹（浸發）：未核實浸發後狀態；不能套用乾枝竹數值。
- 鹹鴨蛋：原來源未列總膳食纖維。
- 皮蛋：原來源未列總膳食纖維。

公開核對頁：網站的`data/food-review.html`。每項原因及原記錄亦保存在`data/food-review.json`。資料來源及常用份量頁已同步更新。

日本官方記錄中，熟烏冬的總纖維及粗鹽的總纖維屬來源括號推估值；本版沿用官方數字並清楚標示，沒有當作逐件實測值。

## 舊作品及草稿

- 已保存於Cloudflare的作品保持原內容、圖片及網址，不會因食材庫更新而改寫。
- 舊草稿的原有克數保留；原來一量杯白飯158克不會變成一碗198克。舊份量選項不再適用時，以原有克數恢復。
- 舊草稿含已抽起食材時，會明確列出被移出的材料，保留其餘材料及菜名，清空受影響的舊步驟，要求重新生成或填寫做法。未改動的原稿有下載按鈕，並保存在同一瀏覽器的更新前備份中。
- 食材、克數及食譜內容不變、只有資料版本更新時，已有概念圖會恢復，不會自動再呼叫AI。含已抽起材料而改了食譜內容時，則不會套用舊圖。
- 新清單載入時會檢查五項數據齊全；若錯誤上傳不完整資料，會停止使用該份資料，不會顯示虛構數值。
