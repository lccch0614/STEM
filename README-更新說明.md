## 學生操作

每個故事約6–8分鐘、4個關卡，逐步加入條件。題型包括單選、方案加理由、指定數量多選及常用份量輸入。選項順序會打亂，同一進度的順序保留；有不止一個合理方案的關卡接受各個符合條件的方案。

方案及理由分開計判斷點；多選題必須選指定數量，不能全選取分。可看提示、修改再試，回顧頁分開顯示首次與目前表現，提示及修改不扣分。不評比體型，也不模擬角色體重增減。

人物故事各自保留進度。本版本使用同一瀏覽器分頁的儲存；重新整理或切換頁面可繼續，關閉分頁後不保證保留，不是跨裝置帳戶紀錄。舊版自由練習進度及食譜草稿使用各自原有的儲存方式。

可在作答途中查相關營養圖鑑，再按「返回本關繼續作答」；已選答案及提示保留。完成故事後，可逐項選用符合條件選擇中的材料到餐盤；不會自動加入、不會自動生成食譜或扣AI額度。

## 教材資料

所有人物、餐牌、售價及明示的產品標籤是教學模擬，不代表真實品牌或市價。計算規則及健康知識附官方來源。常用份量約克數引用目前食材庫已有的份量來源，並核對原配方與新的人數比例。

小強的150厘米、70公斤為可展開的虛構背景；本活動不套用成人BMI作兒童分類，不訂減重餐單。活動以生活決策作教學，而非個人健康評估。

過敏故事只按題目中家長已確認的產品及處理方案判斷；「無乳糖」不等於「不含奶蛋白」，不以試食或少吃一口確認安全。故事可食清單不可套用到現實中所有同名產品。
